Dapur Senja — a fast-paced 2D cooking game: grab ingredients from the bins, cook on the stove, chop on the board, assemble plates to match the order tickets, and serve before time runs out. 150 seconds, 3 hearts, 6 Indonesian recipes, combos and tips.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or run `node main.ts` to build the game output and dossier.
